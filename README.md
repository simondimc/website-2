# Moji projekti

Portfolio hobi projektov risanja (Astro).

## Nov projekt

1. Naredi mapo `src/content/projects/<ime-projekta>/`
2. V mapo dodaj `index.md` (glej obstoječe primere) in slike `01.jpg`, `02.jpg`, ...
3. `git add . && git commit && git push`

## Ukazi

- `npm run dev`: lokalni razvoj
- `npm run build`: produkcijska gradnja v `dist/`
